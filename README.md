# Offshore

A phone web app for Hong Kong domestic helpers. She is the CEO of her own life. She decides every number. Offshore shows the steps and keeps the plan on this phone.

This repository is a **preview**, not a live product.

GitHub Pages is on. The latest preview is:

`https://betomarine.github.io/Offshore/preview/fourth/`

The first preview stays at `preview/first/`. The second preview stays at `preview/second/`. The third preview stays at `preview/third/`. `.github/workflows/preview.yml` publishes `dist` into `preview/fourth` and keeps older preview folders.

```bash
npm install
npm run dev
npm run build
npm run check:logic
npm run check:ui
```
